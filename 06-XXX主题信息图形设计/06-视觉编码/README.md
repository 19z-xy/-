# 视觉编码

围绕叙事重点做设计表达。逐项记录画面元素代表什么、如何映射数据、如何引导视线，以及如何用草图验证可读性。

| 视觉手段 | 设计用途示例 | 本选题方案 |
| --- | --- | --- |
| 点、线、面、体 | 点定位、线连关系、面分区域、体解释结构 |  |
| 色彩 | 色相区分类别，明度区分等级，强调色提示焦点 |  |
| 行距、字距与字号 | 区分标题、正文和注释，保持连续阅读 |  |
| 图像与图形 | 照片提供情境，插画或符号突出识别特征 |  |
| 统计图形 | 条长表现数值，位置表现顺序或测量值 |  |
| ISOTYPE 图形 | 等尺寸象形符号按数量重复，图例注明一枚代表多少单位 |  |
