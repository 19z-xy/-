数据逻辑回答信息怎样组织，表现类型回答图形怎样引导阅读。同一案例可以同时具有地理数据逻辑和混合型表现。五份概念定义通过相对链接指向案例图与分析。

每次收录图例，在案例说明中记录标题、作者或出处、数据粒度、统计口径、图形与视觉编码、阅读路径、可复用方法及限制。用同一次提交更新相应定义的 A–E 小节和链接，并在提交说明写明被新增、修订或限定的原则。图中文字或量尺无法核实时，保留待核实说明。

## 案例维护

补充案例时，将图片与说明放在 `02` 下对应类型的目录中。按「新增图例 → 记录可核实的证据 → 回查 01 中相关定义 → 同次提交更新」维护。概念修订注明案例出处、推导过程和适用范围，个别例外可作为补充说明。图例来源与可核实的作者署名随案例记录。
