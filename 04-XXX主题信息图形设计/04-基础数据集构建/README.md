# 基础数据集构建

每列只存一种字段，每个单元格只存一个值。每行代表一条记录。名义类别、量化数值、图像引用和文字说明各自分列。数值与单位分开，经度与纬度分开。一个对象对应多张图片时，用独立图片表逐张记录，再用对象编号关联。
