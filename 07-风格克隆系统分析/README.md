# 风格分析和克隆系统

唯一规范是同目录的 [风格分析和克隆系统.md](./风格分析和克隆系统.md)。系统版本为 v1.0.0。将目录中的文件放入自己的仓库即可使用本入口。

## 网页启动

上传系统 Markdown 和参考图，发送“启动风格分析和克隆系统。分析附件，建立风格档案，并给我四版通用母版。”已有档案时，上传档案并写明要迁移的主题。模型读到图片后可进行视觉分析。

## 仓库启动

给可访问该仓库的大模型发送：

> 读取本仓库的 README.md 和《风格分析和克隆系统.md》，启动风格分析和克隆系统。用档案 <路径>，把主题改为 <主题>，给我四版可提交提示词及适配摘要。

在仓库中保存风格档案时，可以用 `styles/<风格ID>/<版本>.json`。调用时指定路径及版本。网页模型无法读取仓库时，可直接上传同一规范和档案。

## 记忆后调用

开启相应平台的记忆功能后，在对话中使用 [记忆调用卡](./记忆调用卡.md)。使用前确认模型能读到全文规范及指定档案。需要时补交文档。

[验收用例](./验收用例.md)包含跨主题、系列及阻断场景。
